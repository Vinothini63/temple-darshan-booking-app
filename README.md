# Temple Darshan Booking App

## Project Description
The Temple Darshan Booking App is a DBMS project developed using Python and SQLite. It helps users view temple details, check darshan slots, create bookings, view booking records, and cancel bookings.

## Technologies Used
- Python
- SQLite
- SQL

## Database Tables
1. **Devotees** – Stores devotee details.
2. **Temples** – Stores temple names and locations.
3. **Darshan_Slots** – Stores darshan dates, times, and ticket prices.
4. **Bookings** – Stores booking details and booking status.
5. **Payments** – Stores payment amounts and payment status.

## Features
- View temple details
- View available darshan slots
- Book darshan tickets
- View booking details
- Cancel bookings
- Calculate total ticket amount
- Store payment records

## DBMS Concepts Used
- Primary Key
- Foreign Key
- Table Relationships
- SQL INSERT, SELECT, UPDATE queries
- JOIN operations
- Aggregate and calculation operations

## How to Run
1. Install Python.
2. Make sure SQLite support is available.
3. Download `temple_darshan_booking.py`.
4. Run the program using:

   `python temple_darshan_booking.py`

## Note
This is an academic demonstration project. Payment records are simulated; no real payment is processed.
